Creating a Python environment for ``kaiju``
===========================================

Some of the tools in the ``kaiju`` software, such as
:doc:`makeitso </userGuide/makeitso/index>`, are written in Python, and use
the `kaipy <https://kaipy-docs.readthedocs.io/en/latest/index.html>`_ package.
These pages describe how to set up and configure a Python environment with the
proper prerequisites to use the ``kaiju`` and ``kaipy`` tools.
