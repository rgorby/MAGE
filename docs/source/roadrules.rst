Rules of the Road
=================

.. If you have a problem, please try to find the answer on the wiki (and `Google <https://google.com>`_).

.. ----

.. If you seek help in the `#kaijuhelp <https://nasa-drive-cgs.slack.com/archives/C011V6V7YSJ>`_ slack channel, please be patient and polite.

.. ----

.. If other users encounter issues you have already seen, try to help them.

.. ----

.. If you find an error in the documentation, please correct it (or bring it to our attention in the `#kaijuhelp <https://nasa-drive-cgs.slack.com/archives/C011V6V7YSJ>`_ slack channel).
