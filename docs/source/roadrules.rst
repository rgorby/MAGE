Rules of the Road
=================

If you have a problem, please try to find the answer in this documentation
(and `Google <https://google.com>`_).

If you seek help in the ``#kaijuhelp``
Slack channel, please be patient and polite.

If other users encounter issues you have already seen, try to help them.

If you find an error in the documentation, please bring it to our attention in
the ``#kaijuhelp`` Slack channel.

Instructions for joining the ``#kaijuhelp`` can be found :doc:`here <index>`.
