
**Troubleshooting tips and FAQs** 

Troubleshooting tips
====================

Common problems and solutions


* Delete your build directory and re-do cmake/build/etc
* Check your XML file for parsing problems
* Compile w/ CMAKE_BUILD_TYPE=DEBUG and rerun
