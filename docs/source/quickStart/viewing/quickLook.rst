Quick-look plots for model results
==================================

``dbpic.py``
----------------

This script visualizes output from the program ``calcdb.x``\ , which computes ground magnetometer readings (delta B) corresponding to a ``gamera`` terrestrial magnetosphere run. The script is found at:

.. code-block::

   KAIJUHOME/scripts/quicklook/dbpic.py


Help text for the script can be found using the ``-h`` command-line option:

.. code-block::

   usage: dbpic.py [-h] [-d directory] [-id runid] [-n step] [-k0 layer] [-Jr]

   Creates visualization of ground dB
       NOTE: Assumes ground dB has been calculated using calcdb.x on simulation data.


   optional arguments:
     -h, --help    show this help message and exit
     -d directory  Directory to read from (default: /Users/winteel1)
     -id runid     RunID of data (default: msphere)
     -n step       Time slice to plot (default: -1)
     -k0 layer     Vertical layer to plot (default: 0)
     -Jr           Show radial component of anomalous current (default: False)


As an example, running ``dbpic.py`` on the output generated by the standard ``geo_mpi`` quickstart case generates the following file (\ ``qkdbpic.png``\ ):


.. image:: https://bitbucket.org/repo/kMoBzBp/images/1367296445-qkdbpic.png
   :target: https://bitbucket.org/repo/kMoBzBp/images/1367296445-qkdbpic.png
   :alt: qkdbpic.png


``dstpic.py``
-----------------

This script visualizes Dst output from gamera-RCM. The script is found at:

.. code-block::

   KAIJUHOME/scripts/quicklook/dstpic.py


Help text for the script can be found using the ``-h`` command-line option:

.. code-block::

   usage: dstpic.py [-h] [-d directory] [-id runid] [-tpad time padding]
                    [-swfile filename]

   Creates simple plot comparing SYM-H from OMNI dataset to Gamera-RCM.
       Need to run or point to directory that has the bcwind and msphere.gam files of interest


   optional arguments:
     -h, --help          show this help message and exit
     -d directory        Directory to read from (default: /Users/winteel1)
     -id runid           RunID of data (default: msphere)
     -tpad time padding  Time beyond MHD data (in hours) to plot (default: 8)
     -swfile filename    Solar wind file name (default: bcwind.h5)

``mixpic.py``
-----------------

This script visualizes results from REMIX in a ``gamera.x`` magnetosphere run. The script is found at:

.. code-block::

   KAIJUHOME/scripts/quicklook/mixpic.py


Help text for the script can be found using the ``-h`` command-line option:

.. code-block::

   usage: mixpic.py [-h] [-id runid] [-n step] [-print] [-nflux]

   Creates simple multi-panel REMIX figure for a GAMERA magnetosphere run.
   Top Row - FAC (with potential contours overplotted), Pedersen and Hall Conductances
   Bottom Row - Joule heating rate, particle energy and energy flux

   optional arguments:
     -h, --help  show this help message and exit
     -id runid   RunID of data (default: msphere)
     -n step     Time slice to plot, similar to msphpic.py (default: -1)
     -print      Print list of all steps and time labels (default: False)
     -nflux      Show number flux instead of energy flux (default: False)


As an example, running ``mixpic.py`` on the output generated by the standard ``geo_mpi`` quickstart case generates the following files (\ ``remix_n.png``\ , ``remix_s.png``\ ) (NOTE: Images are large, so they have been reduced in size for use on the wiki):

``msphpic.py``
------------------

This script visualizes results from a ``gamera.x`` magnetosphere run. The script is found at:

.. code-block::

   KAIJUHOME/scripts/quicklook/msphpic.py


Help text for the script can be found using the ``-h`` command-line option:

.. code-block::

   usage: msphpic.py [-h] [-d directory] [-id runid] [-n step] [-bz] [-den] [-jy]
                     [-ephi] [-noion] [-nompi] [-norcm] [-bigrcm] [-src]
                     [-size {small,std,big,dm}]

   Creates simple multi-panel figure for Gamera magnetosphere run
       Top Panel - Residual vertical magnetic field
       Bottom Panel - Pressure (or density) and hemispherical insets


   optional arguments:
     -h, --help            show this help message and exit
     -d directory          Directory to read from (default: /Users/winteel1)
     -id runid             RunID of data (default: msphere)
     -n step               Time slice to plot (default: -1)
     -bz                   Show Bz instead of dBz (default: False)
     -den                  Show density instead of pressure (default: False)
     -jy                   Show Jy instead of pressure (default: False)
     -ephi                 Show Ephi instead of pressure (default: False)
     -noion                Don't show ReMIX data (default: False)
     -nompi                Don't show MPI boundaries (default: False)
     -norcm                Don't show RCM data (default: False)
     -bigrcm               Show entire RCM domain (default: False)
     -src                  Show source term (default: False)
     -size {small,std,big,dm}
                           Domain bounds options (default: std)


As an example, running ``msphpic.py`` on the output generated by the standard ``geo_mpi`` quickstart case generates the following file (\ ``qkpic.png``\ ) (NOTE: Image is large, so it has been reduced in size for use on the wiki):

----------------

.. code-block::

   KAIJUHOME/scripts/quicklook/swpic.py


Help text for the script can be found using the ``-h`` command-line option:

   usage: swpic.py [-h] [-d directory] [-id swid] [-type type]

   Creates simple multi-panel figure for the

     -h, --help    show this help message and exit
     -d directory  Directory to read from (default: /Users/winteel1)
     -id swid      Solar wind file used (default: bcwind.h5)
